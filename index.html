Attack Graph Engine for Enterprise Risk

SDE Intern · C3iHub, IIT Kanpur · Feb–Jul 2026

Security teams face far more known vulnerabilities than they can patch. I built a system that turns scans, network configuration and Active Directory data into ranked attack paths, so a team can see which single fix breaks the most routes to its critical assets.

Phase 1 · ML pipeline

A multi-label classifier mapping CVEs to MITRE ATT&CK techniques, using MiniLM embeddings with CWE/CVSS features and One-vs-Rest logistic regression with per-label thresholds. Near-duplicate CVEs were grouped and split with GroupKFold, so test scores stay honest.

Phase 2 · Graph engine

A Neo4j attack graph of devices, identities, network segments and applications, built by a 3-stage pipeline: fact generation, edge derivation, then traversal checks. Paths are ranked by live EPSS exploit-likelihood scores.
